# Documentation

Project-wide documentation. Documentation of a single part lives next to its code (`poc/server/docs/`, `poc/mobile/docs/`).

| Folder | Content |
|---|---|
| [`project/`](project) | What the project is: [overview](project/overview.md), [requirements](project/requirements.md), [system architecture](project/architecture.md), [glossary](project/glossary.md) |
| [`adr/`](adr) | Architecture decision records – one short file per decision |
| [`consultations/`](consultations) | Notes from consultations with the thesis supervisor |

Every document here starts with a metadata header ( creation date, version) and ends with a revision history – see [CONTRIBUTING.md](../CONTRIBUTING.md#documentation).
