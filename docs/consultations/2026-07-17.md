## Feedback and decisions

- **Sycophancy:** LLMs often agree with the user. The approach must change – the model should not say "you're right" without checking the statement against the scenario.
- **Metrics:** unify how results are reported – either percentages or decimal fractions, not both.
- **WER depends on the language** – keep this in mind when comparing published results.
- **EMS-specific ASR:** check whether models such as EMS-Whisper are actually published or only described in papers.
- **Terminology:** describe the domain terms used in the thesis, e.g. triage.
- **Offline operation:** carrying out an action without access to external resources requires a local set of scenarios.
- **Costs and risks:** estimate the operating costs of the application and analyse risks, especially those related to external providers.
- **References:** use a reference manager such as Zotero, or check the bibliography tools built into LaTeX.
