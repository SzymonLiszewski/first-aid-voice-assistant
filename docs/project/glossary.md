## Technical terms

| Term | Meaning |
|---|---|
| ASR | Automatic speech recognition – converting speech to text. |
| CER / WER | Character / word error rate – the standard measures of ASR quality. |
| GGUF | File format for quantised models used by llama.cpp. |
| LLM | Large language model. |
| LoRA | Low-rank adaptation – a lightweight fine-tuning method. |
| PoC | Proof of concept – the demo in `poc/`. |
| Quantisation | Storing model weights with lower precision to reduce size and speed up inference on weaker devices. |
| RAG | Retrieval-augmented generation – the model answers using fragments retrieved from a knowledge base. |
| TTS | Text-to-speech – reading prompts aloud. |
| VAD | Voice activity detection – finding where speech starts and ends. |
| Event log | Timestamped record of rescue actions created automatically by the assistant. |
| Reference log | Event log prepared by hand for a recording; the automatic log is compared with it. |
